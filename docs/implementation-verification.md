- 独立 mocks 与引用式 combinations，新建默认关闭；统一侧栏、响应 JSON 导入/校验、响应状态码/延迟/头编辑、未保存提示、拖拽与键盘按钮排序、克隆与引用删除保护。

- 角标采用 Shadow DOM、首次接口顺序去重、按实际 URL 命名、最近命中、折叠/键盘/aria-expanded。修复 XHR 立即复用漏记；注入资源转为 ASCII 避免页面字符集误解码；明确保留 CSP，不绕过页面策略。
