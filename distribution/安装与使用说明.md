# Mock Studio macOS 安装与使用

这是 Apple Silicon（M 系列）Mac 的内部测试包，Intel Mac 暂未验证。通过苹果菜单 →「关于本机」查看芯片。包内 Whistle 为独立官方客户端，Mock Studio 为本项目桌面应用。

1. 解压后打开 Whistle 安装包，将 Whistle 拖入「应用程序」。已经安装的用户可保留现有版本及配置，先检查兼容性，不必覆盖。
2. 打开 Mock Studio 安装包，将 Mock Studio 拖入「应用程序」，然后打开。应用会查找 `/Applications/Whistle.app` 并尝试启动或复用 Whistle；无需单独安装 Node 才能使用桌面界面。
3. 在 Whistle 中根据需要配置浏览器或系统代理；调试 HTTPS 时安装并信任根证书并配置 HTTPS 解密。确保目标浏览器实际使用该代理。系统代理可能影响其他应用，用完按需恢复。
4. 选择 Mock Studio「项目菜单」→「导入场景包」，选择 `examples/demo-package.json`，查看预览后导入。启用项目和“示例查询”规则，再验证实际响应和命中记录。

示例地址是 `http://example.test/mock-studio/demo`，只用于代理演示。若 Whistle 在默认端口 `8888`，可在终端用下列命令检查；若端口不同，请按实际配置修改。配置不正确时该保留域名可能无法解析，不能因此认定 Mock 生效。

```bash
curl -i --proxy http://127.0.0.1:8888 --noproxy '' http://example.test/mock-studio/demo
```

期望看到 JSON 示例响应和 `x-mock-source: mock-studio`，并在 Mock Studio 中看到命中记录。每项目至多启用一个高级组合；与组合无关的请求可能透传。涉及真实写操作时先确认目标请求已经被正确接管。

若本机端口 `3000` 或 `17321` 被占用，先确认实际监听程序并处理冲突。配置已保存但 Whistle 同步失败时，不能称为已生效。桌面版日志与数据位于 `~/Library/Application Support/Mock Studio/`；不要分享管理令牌、私钥或敏感数据。

本 Mock Studio 包尚未签名和公证，macOS 可能阻止打开，请遵循组织安全规范。本机已验证构建和隔离 API；尚未在另一台全新设备完成安装、Whistle 联动及 HTTPS 页面命中的完整验收。AI 功能按 `AI配置说明.md` 单独配置。
